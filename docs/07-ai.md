# 07 · AI

Models extract, classify and judge claims. They never decide coverage, never author rules and never produce a
verdict without a rule_key.

## Where models are used
| Use | Workflow | Model class (D-11) | Guardrail |
|---|---|---|---|
| Classification suggestion | D03 | Claude Sonnet 5.5 | A person confirms; citation stored; unsure fields left empty |
| Claim judgement | D04 (claim_judgement shape) | Claude Sonnet 5.5 | Target-language string only; confidence; abstention is withheld |
| Rule and term extraction | K01, K02 | Claude Opus 5.5 (first key), Sonnet 5.5 with a different prompt (second key) | Two independent extractions; a person accepts |
| Source triage | J01 | Claude Haiku 4.5 | A person records horizon items |
| Compliance Worker | L01–L03, after launch | Sonnet class | Retrieval over ref and coverage only; three refusal states |

Anthropic API ids: `claude-sonnet-5-5`, `claude-haiku-4-5-20251001`, `claude-opus-5-5`. Bedrock ids and EU
inference profiles differ and are confirmed in milestone 0; all ids live in configuration.

## One way to call a model
`nutrivo_worker.models.call(purpose, prompt_version, inputs, output_schema)`: temperature 0, timeout, retries,
output validated against a JSON schema, a row in `app.model_calls` (model id, prompt version, input hash, tokens,
cost, latency) and a Langfuse trace. No other code calls a model. Prompts live in `worker/prompts/` and are never
edited in place once used: copy to the next version.

## Evaluation before use
Each claim rule has an evaluation set per language in `worker/evals/claims/<lang>.jsonl`, labelled by a person
(permitted, prohibited, needs evidence). A claim rule may join a ruleset only when, for every language it covers,
agreement with the human labels reaches Cohen's κ ≥ 0.8 on at least 50 examples **and** nothing on the prohibited
set is judged permitted. Until then the claims domain stays partial with a gap. Rerun on every model or prompt change.

## Safety
Label and document text is data: it is passed in delimited blocks with an instruction to ignore instructions inside
it, outputs are schema-validated, and no tools are available during judgement. Only panel text is sent, never names
or emails. Providers: Bedrock in the EU, or the Anthropic API under zero data retention (confirm terms in M0).
