# D01 · Upload artwork and extract

| Domain | Register status | Scope | Milestone |
|---|---|---|---|
| Label checks | PART | BUILD | M3 |

**Actor · trigger:** Editor  
**Design:** Nutrivo 2.0 (label report, artwork pins, coverage node); Mobile; Empty and Error States

## Steps
1. Upload, then app.register_artwork.
2. The 'extract' job reads page size and true scale, panels, the language of each panel, and text objects with bounding box, x-height and cap-height.
3. Typed failures per panel; successful panels persist.
4. Progress over Realtime.

## Database (Workflow Register)
storage.objects insert; artwork_versions insert (sha256); artwork_panels insert per language; text_objects insert (bbox, x_height, cap_height)

**Depends on:** Supabase Storage, extraction pipeline, Realtime

## Must hold
- One row per printed panel (BE-16).
- Both heights on every text object (BE-17).
- Partial results with named failures, never one file-level error (BE-18).
- Idempotent per file hash.

## Failure and edge cases
- Raster or photo: not_assessable 'rasterised'; geometry is never guessed.
- Outlined text: 'outlined_text'.
- Fonts not embedded: 'missing_font'.

## Acceptance IDs (each needs a test carrying the ID in its title; docs/19)
- `D01.main` Upload artwork and extract: the main path works end to end
- `D01.must.1` One row per printed panel (BE-16).
- `D01.must.2` Both heights on every text object (BE-17).
- `D01.must.3` Partial results with named failures, never one file-level error (BE-18).
- `D01.must.4` Idempotent per file hash.
- `D01.fail.1` Raster or photo: not_assessable 'rasterised'; geometry is never guessed.
- `D01.fail.2` Outlined text: 'outlined_text'.
- `D01.fail.3` Fonts not embedded: 'missing_font'.

**Related backend rows:** BE-16, BE-17, BE-18, worker gates
