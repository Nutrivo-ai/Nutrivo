# A02 · Sign in and start a session

| Domain | Register status | Scope | Milestone |
|---|---|---|---|
| Access | PART | BUILD | M1 |

**Actor · trigger:** Member · signs in  
**Design:** Workspace Settings (People, Your account); Onboarding Flow; Account Recovery

## Steps
1. Supabase Auth session.
2. Active memberships loaded (not ended, access_ends_at in the future).
3. More than one workspace: the switcher (N02).
4. A person with a signing grant is asked to enrol TOTP.
5. Audit session.started.

## Database (Workflow Register)
auth.sessions insert; memberships read (role, scope, external, ends_at); signing_grants read (forces 2FA); audit_events insert (session.started)

**Depends on:** A01, A08, A09 for SSO

## Must hold
- An expired or ended membership gives no access (BE-03).
- Signing always requires aal2.

## Failure and edge cases
- Membership ended: 'access removed' page (Account Recovery design).
- Signer without TOTP: enrol before signing.
