# B02 · Use the free label allowance

| Domain | Register status | Scope | Milestone |
|---|---|---|---|
| Workspace and allowance | DRAWN | BUILD | M4 |

**Actor · trigger:** System · when an artwork is registered  
**Design:** Onboarding Flow; Workspace Settings; Plans and Checkout (third and fourth label)

## Steps
1. app.register_artwork decides whether the artwork is new (a product's first).
2. private.consume_allowance records it once (keyed by artwork version) and increments the counter.
3. On the free plan a new artwork is refused when all three are used.
4. Audit allowance.consumed.

## Database (Workflow Register)
allowances read and increment labels_used; artwork_versions read (is_new_artwork); audit_events insert (allowance.consumed)

**Depends on:** C02, D01, M01

## Must hold
- Re-checks, further markets and revised versions never count (BE-32 gate).
- Enforced per workspace.

## Failure and edge cases
