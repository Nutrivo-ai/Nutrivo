# D03 · Classify the product

| Domain | Register status | Scope | Milestone |
|---|---|---|---|
| Label checks | DRAWN | BUILD | M4 |

**Actor · trigger:** Editor confirms  
**Design:** Nutrivo 2.0 (label report, artwork pins, coverage node); Mobile; Empty and Error States

## Steps
1. The worker suggests species, life stage, product class, intended use and PARNUT status from the label text, with a citation.
2. A person confirms or edits.
3. Stored as an insert-only record with citation and provenance.

## Database (Workflow Register)
classifications insert (basis, provenance, confirmed_by)

**Depends on:** D01, K05 ruleset

## Must hold
- Classification comes before any rule (BE-19).
- A new classification makes the previous check stale (new job key).

## Failure and edge cases
