# A03 · Invite a member

| Domain | Register status | Scope | Milestone |
|---|---|---|---|
| Access | DRAWN | BUILD | M1 |

**Actor · trigger:** Admin · People tab  
**Design:** Workspace Settings (People, Your account); Onboarding Flow; Account Recovery

## Steps
1. Admin sets email, role, scope, external flag and an optional end date.
2. app.invite_member checks editor seats for editor-class roles.
3. The 'notify' job generates the token, stores only its hash and sends the email.
4. Audit invitation.sent.

## Database (Workflow Register)
invitations insert (role, scope, external, ends_at, expires_at); subscriptions read (editor_seats); audit_events insert (invitation.sent)

**Depends on:** A01, M02 allowance metering, O01

## Must hold
- Only admins invite.
- The raw token is never stored.
- Viewers never use a seat; external editors do.

## Failure and edge cases
- No seat left: P0033, then the upsell from Plans and Checkout.
- A pending invitation exists: resend, never duplicate.
