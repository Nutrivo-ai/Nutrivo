# H03 · Supplier uploads through a link

| Domain | Register status | Scope | Milestone |
|---|---|---|---|
| Documents and suppliers | DRAWN | BUILD | M8 |

**Actor · trigger:** Supplier without an account  
**Design:** Nutrivo 2.0 (documents); Email Templates

## Steps
1. Edge Function 'supplier-upload' checks the token, MIME type, magic bytes and size (25 MB).
2. The file lands in quarantine; the worker scans it, then promotes it.
3. The request is marked fulfilled.

## Database (Workflow Register)
documents insert via edge function (token-scoped); document_requests update fulfilled

**Depends on:** H02

## Must hold
- The token reaches one request and nothing else; single use for upload.

## Failure and edge cases
- Expired or used token: a generic error that reveals nothing.

## Acceptance IDs (each needs a test carrying the ID in its title; docs/19)
- `H03.main` Supplier uploads through a link: the main path works end to end
- `H03.must.1` The token reaches one request and nothing else; single use for upload.
- `H03.fail.1` Expired or used token: a generic error that reveals nothing.

**Related backend rows:** —

Status: built (T-802): the `supplier-upload` Edge Function takes the token in a POST body only, checks it first (expired, used, unknown and malformed answer the identical 404 `link_unavailable`), then the declared type and the magic bytes (PDF, DOCX, XLSX) and 25 MiB, stores the file in quarantine at `<workspace>/<request>/<file>` and app.accept_supplier_upload uses the link and queues the `scan` job in one transaction. The worker scans with ClamAV (clamscan in the worker image) and app.record_scan_result promotes a clean file as a new row (the quarantine row stays as history) and fulfils the request; an infected file is recorded rejected and never leaves quarantine. S-NV2-028 serves one request per link; the design's "upload once, reaches many" and "replace an expired document" contradict H03.must.1 and are left out (#69). `H03.main`, `H03.must.1` and `H03.fail.1` are tested in supabase/tests/app/97_supplier_links.test.sql, supabase/functions/supplier-upload/upload.test.mjs (via worker/tests/test_scan.py), worker/tests/test_supplier_links_pg.py, apps/web/src/lib/public/supplier.test.ts and apps/web/tests/e2e/suppliers.spec.ts.
