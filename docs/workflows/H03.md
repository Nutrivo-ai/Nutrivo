# H03 · Supplier uploads through a link

| Domain | Register status | Scope | Milestone |
|---|---|---|---|
| Documents and suppliers | DRAWN | BUILD | M8 |

**Actor · trigger:** Supplier without an account  
**Design:** Nutrivo 2.0 (documents); Email Templates

## Steps
1. Edge Function 'supplier-upload' checks the token, MIME type, magic bytes and size (25 MB).
2. The file lands in quarantine; the worker scans it, then promotes it.
3. The request is marked fulfilled.

## Database (Workflow Register)
documents insert via edge function (token-scoped); document_requests update fulfilled

**Depends on:** H02

## Must hold
- The token reaches one request and nothing else; single use for upload.

## Failure and edge cases
- Expired or used token: a generic error that reveals nothing.
