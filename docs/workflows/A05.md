# A05 · Change a role, scope or end date

| Domain | Register status | Scope | Milestone |
|---|---|---|---|
| Access | DRAWN | BUILD | M1 |

**Actor · trigger:** Admin  
**Design:** Workspace Settings (People, Your account); Onboarding Flow; Account Recovery

## Steps
1. Edit in People.
2. app.change_member (to build) checks seats.
3. Update the membership; audit before and after.

## Database (Workflow Register)
memberships update; audit_events insert (before and after values)

**Depends on:** A03, M02

## Must hold
- The last admin can never be removed or demoted.
- A role change grants no signing authority (BE-04).
- Becoming external revokes signing grants in the same transaction.

## Failure and edge cases
- Last-admin demotion refused.
- Seat limit: upsell.
