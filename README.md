# Nutrivo

Label compliance for pet food, checked against encoded EU feed law per market and per printed language panel,
with the rule, citation and provenance behind every result. Honest by construction: no rule, no verdict.

This repository is the build hand-off. Claude Code does the engineering inside the guardrails written here;
people own decisions, accounts, regulatory content acceptance and reviews.

| You are | Start with |
|---|---|
| A founder starting the build | `START-HERE.md` (then Claude Code runs `BOOTSTRAP.md`) |
| Claude Code | `CLAUDE.md`, `BOOTSTRAP.md`, `docs/15-build-protocol.md` |
| Reviewing a decision or a pull request | `docs/02-decisions.md`, `docs/09-security.md`, `docs/13-testing.md` |

State on hand-off (8 Oct 2026): database schema, row-level security, insert-only enforcement and the
"no rule, no verdict" guard are written and pass 44 gate tests on PostgreSQL 16. Synthetic label fixtures with
exact ground truth are generated by `make fixtures`. Application code is built milestone by milestone (M0–M11).
