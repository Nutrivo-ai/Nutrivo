# spec/: the target state

These files are what "done" means. CI enforces them; founders own them (CODEOWNERS).
- `acceptance.yaml`: one acceptance ID per main path, must-hold and failure case of every workflow. Generated from
  scripts/workflows/data.py by `python scripts/workflows/render.py`; CI fails if it is stale.
- `screens.yaml`: every designed screen. Generated by T-012 and frozen at gate G4.
- `nfr.yaml`: budgets for performance, availability, quality, security and cost.
- `conformance-baseline.json`: acceptance IDs that have passed. The list only grows; CI fails if any of them stop passing.
To change the target, open a PR here with the reason, and record the decision in docs/02-decisions.md.
