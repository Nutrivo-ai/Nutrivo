There is no separate help panel. The Compliance Worker is already docked on every screen and already reads the current object, so help belongs there rather than in a second surface. One thing is added: a small authored glossary the Worker returns verbatim instead of in its own words.

Two kinds of question, answered two different ways

"Why is this Not assessed?" is a question about this finding, and the Worker answers it from the record. "What does Not assessed mean?" is a definition, and a model paraphrasing it differently each time would be a liability in a compliance tool. Definitions come from an authored glossary, versioned with the ruleset, returned word for word and marked as authored.

How somebody confused gets in

A blank chat box is a bad answer for a person who does not yet know what to ask. So the entry points are affordances on the thing they are confused about, and each one pre-fills a question rather than opening an empty panel.
