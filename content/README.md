- `candidates/`: extraction targets (`eu-core.yaml` for rules, `eu-core-terms.yaml` for terms) and candidate rules.
  Claude Code may write here.
- `accepted/`: exports of accepted content, written only by the acceptance flow after a person clicks accept.
  Claude Code is denied write access.
